======================================================================
 거지탈출 (richman DB) 백엔드 쿼리 가이드 : 모듈 1~4
======================================================================

 모든 값 자리는 ? (플레이스홀더 사용)
 정산 기간(start_day 기준) 시작일/종료일은 Java(DateUtil)에서 계산해 쿼리에는 날짜 범위만 전달
 기간 관련 조회는 (A) 전체 / (B) 기간 한정 두 버전, 회의에서 하나로 확정


==================================================
 모듈 1. 회원 관리 (User)
==================================================

[1-1] 로그인 인증
SELECT user_id, login_id, user_name, income, point_balance FROM user WHERE login_id = ? AND password = ?;

   순서   값         타입
   1      login_id   String
   2      password   String

   결과가 0행이면 로그인 실패


[1-2] 아이디 중복 검사
SELECT COUNT(*) AS cnt FROM user WHERE login_id = ?;

   순서   값         타입
   1      login_id   String

   cnt가 0이면 사용 가능, 1 이상이면 중복


[1-3] 회원가입
INSERT INTO user (login_id, password, user_name, birth_date, gender, phone, job, address, income) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?);

   순서   값           타입
   1      login_id     String
   2      password     String
   3      user_name    String
   4      birth_date   Date
   5      gender       String
   6      phone        String
   7      job          String
   8      address      String
   9      income       int

   user_id는 자동 증가, point_balance는 기본값 0이라 넣지 않음


[1-4] 회원 상세 조회 (마이페이지)
SELECT user_id, login_id, user_name, birth_date, gender, phone, job, address, income, point_balance FROM user WHERE user_id = ?;

   순서   값         타입
   1      user_id    int


[1-5] 회원 정보 수정
UPDATE user SET user_name = ?, phone = ?, job = ?, address = ?, income = ? WHERE user_id = ?;

   순서   값           타입
   1      user_name    String
   2      phone        String
   3      job          String
   4      address      String
   5      income       int
   6      user_id      int

   login_id는 가입 후 변경 불가라 수정 대상에서 제외


[1-6] 비밀번호 변경
UPDATE user SET password = ? WHERE user_id = ?;

   순서   값               타입
   1      password(new)    String
   2      user_id          int


==================================================
 모듈 2. 지출 관리 (Expense)
==================================================

[2-1] 지출 등록
INSERT INTO expense (user_id, medium_id, item_name, expense_amount, spent_date, memo, is_fixed) VALUES (?, ?, ?, ?, ?, ?, ?);

   순서   값                타입
   1      user_id           int
   2      medium_id         int
   3      item_name         String
   4      expense_amount    int
   5      spent_date        Date
   6      memo              String
   7      is_fixed          boolean (0 또는 1)


[2-2] 지출 수정
UPDATE expense SET medium_id = ?, item_name = ?, expense_amount = ?, spent_date = ?, memo = ?, is_fixed = ? WHERE expense_id = ?;

   순서   값                타입
   1      medium_id         int
   2      item_name         String
   3      expense_amount    int
   4      spent_date        Date
   5      memo              String
   6      is_fixed          boolean (0 또는 1)
   7      expense_id        int


[2-3] 지출 삭제
DELETE FROM expense WHERE expense_id = ?;

   순서   값             타입
   1      expense_id     int


[2-4] 지출 내역 조회 (공통 뼈대)
SELECT e.expense_id, e.medium_id, m.medium_name, l.large_id, l.large_name, e.item_name, e.expense_amount, e.spent_date, e.memo, e.is_fixed FROM expense e JOIN medium_category m ON e.medium_id = m.medium_id JOIN large_category l ON m.large_id = l.large_id WHERE e.user_id = ? ORDER BY e.spent_date DESC, e.expense_id DESC;

   순서   값         타입
   1      user_id    int

   위 뼈대의 WHERE에 조건만 추가해 세 가지로 재사용

   (A) 전체 조회
       그대로 사용

   (B) 기간 한정
       WHERE e.user_id = ? AND e.spent_date BETWEEN ? AND ?

       순서   값          타입
       1      user_id     int
       2      시작일      Date
       3      종료일      Date

   (검색) 항목명 검색
       WHERE e.user_id = ? AND e.item_name LIKE ?

       순서   값         타입
       1      user_id    int
       2      keyword    String   (Java에서 "%" + 키워드 + "%" 형태로 전달)


[2-5] 대분류별 집계와 비율 (도넛차트)
SELECT l.large_id, l.large_name, SUM(e.expense_amount) AS total_amount, ROUND(SUM(e.expense_amount) * 100.0 / SUM(SUM(e.expense_amount)) OVER (), 1) AS ratio_percent FROM expense e JOIN medium_category m ON e.medium_id = m.medium_id JOIN large_category l ON m.large_id = l.large_id WHERE e.user_id = ? GROUP BY l.large_id, l.large_name ORDER BY total_amount DESC;

   (A) 전체

       순서   값         타입
       1      user_id    int

   (B) 기간 한정
       WHERE e.user_id = ? AND e.spent_date BETWEEN ? AND ?

       순서   값          타입
       1      user_id     int
       2      시작일      Date
       3      종료일      Date


[2-6] 수입 대비 지출 비율
총지출만 쿼리로 구하고, income과의 나눗셈은 Java에서 처리
사용률(%) = 총지출 * 100 / income

   (A) 전체 총지출
SELECT COALESCE(SUM(expense_amount), 0) AS total_expense FROM expense WHERE user_id = ?;

       순서   값         타입
       1      user_id    int

   (B) 기간 한정 총지출
SELECT COALESCE(SUM(expense_amount), 0) AS total_expense FROM expense WHERE user_id = ? AND spent_date BETWEEN ? AND ?;

       순서   값          타입
       1      user_id     int
       2      시작일      Date
       3      종료일      Date

   income은 1-4 회원 조회로 확보


==================================================
 모듈 3. 카테고리 (Category)
==================================================

[3-1] 전체 대분류 목록
SELECT large_id, large_name FROM large_category ORDER BY large_id;

   파라미터 없음


[3-2] 특정 대분류의 중분류 목록 (드롭다운 연동)
SELECT medium_id, medium_name FROM medium_category WHERE large_id = ? ORDER BY medium_id;

   순서   값          타입
   1      large_id    int


==================================================
 모듈 4. 예산 관리 (Budget)
==================================================

 budget_scope 값은 'LARGE'(대분류별) 또는 'TOTAL'(월 전체)
 large_id는 LARGE면 대분류 번호, TOTAL이면 NULL

[4-1] 예산 등록
INSERT INTO budget (user_id, large_id, limit_amount, budget_scope) VALUES (?, ?, ?, ?);

   순서   값               타입
   1      user_id          int
   2      large_id         int      (TOTAL이면 setNull(2, Types.INTEGER))
   3      limit_amount     int
   4      budget_scope     String   ('LARGE' 또는 'TOTAL')


[4-2] 예산 목록 조회 (사용자별)
SELECT b.budget_id, b.large_id, l.large_name, b.limit_amount, b.budget_scope FROM budget b LEFT JOIN large_category l ON b.large_id = l.large_id WHERE b.user_id = ? ORDER BY b.budget_scope, b.large_id;

   순서   값         타입
   1      user_id    int

   TOTAL 행은 large_id가 NULL이라 LEFT JOIN 사용, large_name은 NULL로 나옴


[4-3] 예산 사용률과 잔액
사용/잔액 계산에 지출 기간이 필요해 시작일/종료일을 Java에서 전달
대분류(LARGE)와 전체(TOTAL)는 지출 합산 범위가 달라 쿼리를 분리
사용률(%) = used * 100 / limit_amount, 잔액 = limit_amount - used, 둘 다 Java에서 계산

   대분류별 예산 (LARGE)
SELECT b.limit_amount, (SELECT COALESCE(SUM(e.expense_amount), 0) FROM expense e JOIN medium_category m ON e.medium_id = m.medium_id WHERE e.user_id = b.user_id AND m.large_id = b.large_id AND e.spent_date BETWEEN ? AND ?) AS used FROM budget b WHERE b.user_id = ? AND b.large_id = ?;

       순서   값          타입
       1      시작일      Date
       2      종료일      Date
       3      user_id     int
       4      large_id    int

   전체 예산 (TOTAL)
SELECT b.limit_amount, (SELECT COALESCE(SUM(e.expense_amount), 0) FROM expense e WHERE e.user_id = b.user_id AND e.spent_date BETWEEN ? AND ?) AS used FROM budget b WHERE b.user_id = ? AND b.budget_scope = 'TOTAL';

       순서   값          타입
       1      시작일      Date
       2      종료일      Date
       3      user_id     int
