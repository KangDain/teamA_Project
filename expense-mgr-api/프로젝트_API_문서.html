CHAPTER 0

프로젝트 개요 & myJava Mgr 아키텍처

이 프로젝트는 C:\Java\myJava 폴더의 전통적인 DBConnectionMgr (커넥션 풀 싱글톤) + XxxMgr + XxxBean 패턴 기반의 초경량 REST API 백엔드입니다.

아키텍처 패턴

DBConnectionMgr

  • 싱글톤 커넥션 풀
  • con = pool.getConnection()
  • pool.freeConnection(con, pstmt, rs)

XxxMgr (10개)

  • UserMgr, ExpenseMgr 등
  • Vector<XxxBean> 반환 방식
  • PreparedStatement SQL 처리

XxxBean (13개)

  • UserBean, ExpenseBean 등
  • JavaBean 규격 (Getter/Setter)
  • JSON 자동 직렬화

회원 관리 (User)

로그인, 회원가입, 마이페이지 정보 수정, 비밀번호 변경, 포인트 잔액 갱신을 담당합니다. UserBean UserMgr UserMgrHandler

BEAN
UserBean
USER 테이블 데이터 전달 객체 (JavaBean)
필드명타입컬럼설명

loginIdStringlogin_id로그인 아이디 (중복 불가)
passwordStringpassword비밀번호
userNameStringuser_name이름
incomeintincome월 수입
pointBalanceintpoint_balance보유 포인트 잔액

REST API 서버 실행 명령어

# 2. Executable JAR로 실행
java -jar C:\Java\expense-mgr-api\target\expense-mgr-api-1.0.0.jar

# 3. IDE에서 실행
src/main/java/api/MgrApiServer.java 우클릭 ➔ Run (실행)
